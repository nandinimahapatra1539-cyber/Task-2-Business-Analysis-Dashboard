# Business Analysis Dashboard (Task 2)

## 📌 Project Overview
This project focuses on analyzing business performance data to uncover key insights regarding sales, customer behavior, and operational efficiency. The goal is to provide actionable recommendations to optimize revenue and improve decision-making.

## 🛠️ Tech Stack & Tools Used
*   **Excel:** Used for initial data cleaning, exploratory data analysis (EDA), and creating pivot tables.
*   **SQL (PostgreSQL):** Used for advanced data querying, table joins, and aggregating key business metrics.
*   **Power BI:** Developed an interactive dashboard to visualize trends and KPIs.

## 📂 Repository Structure
*   📁 `assignment 2/`
    *   📄 `Excel_pivot_Analysis.xlsx` - Cleaned data and pivot calculations.
    *   📄 `join.sql` - Database queries used for analysis.
    *   📄 `power bi assignment_v2.pbix` - Interactive visualization dashboard.
    *   📄 `BUSINESS SUMMARY REPORT1.pdf` - Final executive summary and recommendations.

## 📊 Key Insights Found
**Highest Revenue Source:** Identified that the top-performing product category contributes over 35% of total sales revenue.
**Sales Trends:** Discovered a distinct quarterly sales peak driven by seasonal customer demand patterns.

## 🚀 Actionable Recommendations
1. **Target High-Margin Segments:** Allocate more marketing resources toward the top-performing customer segments identified during data analysis.
2. **Optimize Inventory:** Adjust inventory cycles dynamically to prevent stock shortages during peak seasonal quarters.
